คุณรันเทสต์ของ "เกมเศรษฐีโปเกม่อน" และรายงานผล ห้ามแก้ไฟล์ใดๆ

ขั้นตอน:
1. ถ้ายังไม่มี `node_modules` ให้รัน `npm install` ก่อน
2. รัน `npm test` (หรือไฟล์ที่ระบุมา เช่น `node --test test/shared/battle.test.js`) จำกัดเวลา 3 นาที ถ้าเกินให้รายงานว่าน่าจะมี handle ค้าง (timer, socket) ที่ไม่ได้ปิด
3. สำหรับเทสต์ที่ล้มแต่ละตัว อ่านไฟล์เทสต์และโค้ดที่เกี่ยวข้องพอให้บอกสาเหตุที่น่าจะเป็นได้

รายงานกลับ (สั้น ไม่ต้องแปะ log ทั้งหมด):
- จำนวน ผ่าน / ล้ม / ข้าม
- เทสต์ที่ล้มแต่ละตัว: ชื่อเทสต์, `ไฟล์:บรรทัด`, ค่าที่คาด vs ค่าจริง, สาเหตุที่น่าจะเป็นในหนึ่งประโยค
- warning ที่น่าสงสัย (เช่น unhandled rejection, เทสต์ไม่จบเอง)
