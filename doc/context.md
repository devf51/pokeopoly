# เกมเศรษฐีโปเกม่อน — สเปกเวอร์ชันแรก

เกมกระดานออนไลน์แนวเศรษฐีผสมโปเกม่อน ผู้เล่นทอยลูกเต๋าเดินรอบกระดาน ตกช่องไหนมีสิทธิ์จับโปเกม่อนในช่องนั้น ท้าสู้กับผู้เล่นอื่นได้ เมื่อทุกคนเดินครบ 2 รอบ ใครมีเงินมากที่สุด (รวมมูลค่าโปเกม่อน) ชนะ

> เป็นแฟนเกมส่วนตัว เล่นกันในกลุ่มเพื่อน ไม่เผยแพร่สาธารณะ ไม่หารายได้ (ใช้ชื่อและภาพโปเกม่อนจริง)

---

## 1. เทคโนโลยีและการเล่นออนไลน์

| หัวข้อ | ข้อตกลง |
|---|---|
| ฝั่งเซิร์ฟเวอร์ | Node.js + Express + Socket.IO |
| ฝั่งหน้าเว็บ | HTML + CSS + JavaScript ธรรมดา ไม่มีขั้นตอน build |
| การรัน | เซิร์ฟเวอร์เดียว พอร์ตเดียว (เช่น 3000) เปิดด้วย `npm start` |
| ที่ host | คอมของเจ้าของเกม เพื่อนเข้าผ่าน LAN (`http://IP:3000`) หรือ Tailscale ถ้าอยู่คนละบ้าน |
| ห้อง | ห้องละ 2–4 คน เข้าด้วยรหัสห้องและชื่อเล่น ไม่มีระบบบัญชี |
| หลุดจากเกม | กลับเข้าห้องเดิมด้วยชื่อเดิมได้ |
| หมดเวลา | ไม่ทำอะไรใน 60 วินาที ระบบเล่นแทน (ทอยเดิน และไม่จับ) |
| สถานะเกม | เก็บในหน่วยความจำของเซิร์ฟเวอร์ ไม่ใช้ฐานข้อมูล |
| ความยุติธรรม | เซิร์ฟเวอร์เป็นคนทอยเต๋าและตัดสินผลทั้งหมด |
| เทสต์ | เทสต์กติกาเกมใน `shared/` ด้วย `node --test` |

### โครงสร้างโปรเจกต์

```
server/   Node.js + Express + Socket.IO
public/   หน้าเว็บ HTML/CSS/JS
shared/   กติกาเกม (ทอยเต๋า จับ สู้ ตารางธาตุ) ใช้ร่วมกันทั้งเซิร์ฟเวอร์และเบราว์เซอร์
data/     pokedex.json
doc/      เอกสาร
```

### ข้อมูลโปเกม่อน
- Gen 1 ครบ 151 ตัว
- `data/pokedex.json` สร้างครั้งเดียวด้วยสคริปต์ที่ดึงจาก PokéAPI เก็บ: ชื่อ ธาตุ ค่าสถานะรวม (BST) และ URL ภาพ
- ภาพโหลดผ่าน URL ของ PokéAPI ไม่เก็บไฟล์ภาพไว้ในโปรเจกต์

## 2. กระดาน

- 32 ช่อง เดินด้วยลูกเต๋า 1 ลูก (1d6) ครบ 2 รอบใช้ประมาณ 18 ตาต่อคน

| ช่อง | จำนวน | หน้าที่ |
|---|---|---|
| จุดเริ่มต้น | 1 | รับเงินเดือน ซื้อบอล ขายโปเกม่อน |
| Poké Mart | 2 | ซื้อบอล |
| Pokémon Center | 2 | รักษาโปเกม่อนที่หมดสภาพ |
| ช่องโปเกม่อน | 27 | จับโปเกม่อน แบ่ง 5 โซนตามระยะห่างจากจุดเริ่มต้น |

- ยิ่งไกลจากจุดเริ่มต้น ยิ่งเป็นโซนที่หายากและมีค่า
- จัดโปเกม่อนเข้าโซน 1–5 อัตโนมัติตามค่าสถานะรวม (BST)
- ทุกช่องโปเกม่อนมีตัวสุ่มรอไว้ 1 ตัว เมื่อมีคนตกช่อง (จับได้หรือหนีไป) สุ่มตัวใหม่มาแทน
- ผู้เล่นทั่วไปเห็นแค่โซนของช่อง ไม่เห็นว่ามีตัวอะไร (ยกเว้น Professor)
- ตัวตำนาน (Articuno, Zapdos, Moltres, Mewtwo, Mew) มีโอกาสออก 5% ต่อการสุ่มในโซน 5 แต่ละตัวมีได้แค่ตัวเดียวในเกม จับไปแล้วจะไม่ออกอีก

---

## 3. ลำดับในแต่ละตา

1. ทอยเดิน (ใช้ความสามารถของ Ranger หรือตัวเริ่มต้นได้ในขั้นนี้)
2. ทำตามหน้าที่ของช่อง (จับ / ซื้อ / รักษา / ขาย)
3. ถ้ามีผู้เล่นอื่นอยู่ในช่องเดียวกัน เลือกท้าสู้ได้ 1 คน
4. จบตา

- ลำดับผู้เล่นสุ่มตอนเริ่มเกม
- เดินผ่านจุดเริ่มต้นได้เงินเดือน แต่ซื้อหรือขายได้เฉพาะตอนหยุดที่จุดเริ่มต้นพอดี
- ตอนครบรอบที่ 2 ให้หยุดที่จุดเริ่มต้นเสมอ ไม่ว่าแต้มเกินเท่าไร ได้เงินเดือนและซื้อขายได้

---

## 4. การจับ

- ทอย 1d6 + โบนัสบอล ต้องได้เท่ากับหรือเกินเลขเป้า

| บอล | โบนัส | ราคา |
|---|---|---|
| Poké Ball | +0 | 50 |
| Great Ball | +1 | 120 |
| Ultra Ball | +2 | 250 |

| โซน | เลขเป้า | มูลค่า |
|---|---|---|
| 1 | 2+ | 50 |
| 2 | 3+ | 100 |
| 3 | 4+ | 200 |
| 4 | 5+ | 400 |
| 5 | 6+ | 800 |
| ตำนาน | 7+ (ต้องใช้ Great Ball ขึ้นไป) | 2000 |

- ใช้บอล 1 ลูกต่อการโยน 1 ครั้ง โยนได้ครั้งเดียวต่อการตกช่อง
- ถ้าพลาด โปเกม่อนหนีไป
- ไม่มีบอลก็จับไม่ได้
- เก็บโปเกม่อนได้ไม่จำกัด

---

## 5. การต่อสู้

- คนที่เดินมาตกช่องเป็นคนท้า เลือกท้าได้ 1 คนจากคนที่อยู่ในช่องเดียวกัน อีกฝ่ายปฏิเสธไม่ได้
- ต่างคนต่างเลือกโปเกม่อนที่ยังสู้ได้ 1 ตัว (ใช้ตัวเริ่มต้นได้)
- แต่ละฝ่ายทอย 1d6 + 1 ถ้าได้เปรียบธาตุ
  - ใช้ตารางธาตุจริง ถ้าธาตุใดธาตุหนึ่งของเราชนะทางธาตุใดธาตุหนึ่งของอีกฝ่าย ได้ +1 (ได้สูงสุด +1 ไม่บวกซ้อน)
  - อาจได้ +1 ทั้งสองฝ่ายก็ได้
- ฝ่ายแพ้: โปเกม่อนตัวนั้นหมดสภาพ และจ่ายเงิน 10% ของเงินที่มีให้ฝ่ายชนะ
- เสมอ: ไม่มีอะไรเกิดขึ้น
- ท้าไม่ได้ ถ้า:
  - อีกฝ่ายไม่มีโปเกม่อนที่ยังสู้ได้เลย
  - อีกฝ่ายเดินครบ 2 รอบแล้ว

### โปเกม่อนที่หมดสภาพ
- ขายไม่ได้
- ถ้ายังหมดสภาพอยู่ตอนจบเกม นับมูลค่าเป็น 0
- รักษาที่ Pokémon Center จ่าย 20% ของมูลค่าตัวนั้น เลือกได้ว่าจะรักษาตัวไหน ตัวเริ่มต้นรักษาฟรี

## 6. เศรษฐกิจ

| หัวข้อ | ค่า |
|---|---|
| เงินเริ่มต้น | 500 |
| บอลเริ่มต้น | Poké Ball 5 ลูก |
| เงินเดือน (ผ่านจุดเริ่มต้น) | 200 (Merchant ได้ 300) |
| ขายโปเกม่อน | 100% ของมูลค่า ขายได้ที่จุดเริ่มต้นเท่านั้น |
| โบนัสคนเข้าเส้นชัยเป็นคนแรก | 300 |

- เงินได้จากเงินเดือนและการขายโปเกม่อนเท่านั้น
- ตัวเลขทั้งหมดเป็นจุดตั้งต้น ปรับสมดุลทีหลังได้

---

## 7. โปเกม่อนเริ่มต้น

เลือก 1 ตัวตอนเริ่มเกม ความสามารถพิเศษใช้ได้ครั้งเดียวต่อเกม ใช้สู้ได้ แต่ขายไม่ได้และไม่นับมูลค่าตอนจบ

| ตัวเริ่มต้น | ความสามารถ (ครั้งเดียวต่อเกม) |
|---|---|
| Bulbasaur | จับสำเร็จแน่นอน 1 ครั้ง (ยกเว้นตัวตำนาน) |
| Charmander | ชนะการต่อสู้อัตโนมัติ 1 ครั้ง |
| Squirtle | วาร์ปไปช่องไหนก็ได้ภายใน 6 ช่องข้างหน้า |
| Pikachu | ทอยเต๋าเดินหรือจับใหม่ 1 ครั้ง |

---

## 8. คลาสอาชีพ

เลือกตอนเริ่มเกม หลายคนเลือกคลาสซ้ำกันได้ ความสามารถที่จำกัดจำนวนครั้งใช้ได้ 2 ครั้งต่อเกม

| คลาส | ความสามารถ |
|---|---|
| Catcher (นักจับ) | ทอยจับได้ +1 เสมอ |
| Merchant (พ่อค้า) | ร้านลดราคา 30% และได้เงินเดือน 300 |
| Ranger (นักเดินทาง) | ทอยเดินใหม่ หรือขยับบวกลบ 1 ช่อง (2 ครั้งต่อเกม ใช้โควตาร่วมกัน) |
| Professor (นักวิจัย) | มองเห็นโปเกม่อนใน 6 ช่องข้างหน้าได้ตลอดเกม และทอยจับใหม่ได้ (2 ครั้งต่อเกม) |

---

## 9. จบเกมและผู้ชนะ

- ผู้เล่นที่เดินครบ 2 รอบหยุดเดินที่จุดเริ่มต้น
  - ยังขายโปเกม่อนได้
  - ถูกท้าสู้ไม่ได้
- คนที่เข้าเส้นชัยเป็นคนแรกได้โบนัส 300
- เมื่อทุกคนครบ 2 รอบ เกมจบ
- แปลงโปเกม่อนที่ยังสู้ได้เป็นเงินตามมูลค่า ตัวที่หมดสภาพนับ 0 ตัวเริ่มต้นไม่นับ
- ใครมีเงินรวมมากที่สุดชนะ

---

## 10. หน้าตา

- กระดานสี่เหลี่ยมวนรอบแบบเกมเศรษฐี แต่ละโซนมีสีต่างกัน
- ภาพโปเกม่อนเป็น sprite จาก PokéAPI
- มีแอนิเมชันทอยเต๋าและตัวหมากเดิน
- UI ภาษาไทย ชื่อโปเกม่อนภาษาอังกฤษ
- เน้นเล่นบนคอมพิวเตอร์ แต่มือถือก็ต้องเล่นได้

---

## 11. ไม่มีในเวอร์ชันแรก

- การ์ดเหตุการณ์
- การเทรดโปเกม่อน
- เสียง
- แชท
- ระบบบัญชีผู้ใช้
- บันทึกประวัติการเล่น
- บอท AI
