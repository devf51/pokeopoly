# เกมเศรษฐีโปเกม่อน

เกมกระดานออนไลน์ 2–4 คน แนวเศรษฐีผสมโปเกม่อน Gen 1 ทอยลูกเต๋าเดินรอบกระดาน 32 ช่อง จับโปเกม่อน ท้าสู้กัน เดินครบ 2 รอบ ใครมีเงินรวมมูลค่าโปเกม่อนมากที่สุดชนะ
เจ้าของเกมเปิดเซิร์ฟเวอร์บนคอมของตัวเอง เพื่อนเข้าเล่นผ่านเบราว์เซอร์ (มือถือก็เล่นได้)

> **คำเตือน:** นี่เป็นแฟนเกมส่วนตัว เล่นกันในกลุ่มเพื่อน ไม่เผยแพร่สาธารณะ และไม่หารายได้
> ชื่อและภาพโปเกม่อนเป็นลิขสิทธิ์ของ Nintendo / Game Freak / The Pokémon Company
> เกมนี้ไม่ได้เกี่ยวข้องหรือได้รับการรับรองจากบริษัทเหล่านั้น ภาพโหลดจาก PokéAPI ตอนเล่น ไม่มีไฟล์ภาพอยู่ในโปรเจกต์

## ติดตั้ง

ต้องมี [Node.js](https://nodejs.org) (ทดสอบกับ Node 24) แล้วรันในโฟลเดอร์โปรเจกต์:

```bash
npm install
```

## เปิดเซิร์ฟเวอร์

```bash
npm start
```

เซิร์ฟเวอร์ฟังพอร์ต 3000 (เปลี่ยนได้ด้วย `PORT=4000 npm start`) และพิมพ์ URL ออกมา เช่น

```
เซิร์ฟเวอร์เกมเศรษฐีโปเกม่อนพร้อมแล้ว
  เครื่องนี้:  http://localhost:3000
  ให้เพื่อนเข้า: http://192.168.1.20:3000
```

- เจ้าของเกมเปิด `http://localhost:3000` แล้วกด "สร้างห้อง" จะได้รหัสห้อง 4 ตัวอักษร
- เพื่อนเปิด URL ที่ขึ้นหลัง "ให้เพื่อนเข้า" ใส่ชื่อเล่นกับรหัสห้อง แล้วกด "เข้าห้อง"
- ทุกคนเลือกคลาสและโปเกม่อนตัวเริ่มต้น แล้วเจ้าของห้องกด "เริ่มเกม"
- ถ้าหลุดจากเกม เปิดหน้าเว็บใหม่แล้วจะกลับเข้าห้องเดิมให้เอง (หรือเข้าห้องด้วยชื่อเดิม)
- ถ้าไม่ทำอะไรในตาตัวเองนาน 60 วินาที ระบบจะเล่นแทน (ทอยเดิน และไม่จับ)

## เพื่อนอยู่บ้านเดียวกัน (LAN)

ให้เพื่อนต่อ Wi-Fi หรือเครือข่ายเดียวกับเครื่องที่เปิดเซิร์ฟเวอร์ แล้วเข้า URL ที่เซิร์ฟเวอร์พิมพ์ออกมาตอน `npm start`

ถ้าเพื่อนเข้าไม่ได้ อาจเป็นเพราะ firewall ของเครื่องที่เปิดเซิร์ฟเวอร์ปิดพอร์ตไว้ อนุญาตพอร์ต 3000 ด้วยคำสั่ง (Ubuntu/Debian ที่ใช้ ufw):

```bash
sudo ufw allow 3000/tcp
```

ถ้าเปลี่ยนพอร์ตด้วย `PORT` ให้อนุญาตพอร์ตนั้นแทน

## เพื่อนอยู่คนละบ้าน (Tailscale)

ใช้ [Tailscale](https://tailscale.com) ต่อเครื่องทุกคนเข้าเครือข่ายส่วนตัวเดียวกัน ไม่ต้องเปิดพอร์ตออกอินเทอร์เน็ต

1. ทุกคน (เจ้าของเกมและเพื่อน) ติดตั้ง Tailscale
2. ทุกคนล็อกอินเข้า **เครือข่าย (tailnet) เดียวกัน** (เจ้าของเกมเชิญเพื่อน หรือแชร์เครื่องที่เปิดเซิร์ฟเวอร์ให้เพื่อน)
3. เจ้าของเกมดู IP ของเครื่องที่เปิดเซิร์ฟเวอร์ด้วย `tailscale ip -4` (จะได้เลขขึ้นต้น `100.`)
4. เพื่อนเปิด `http://<Tailscale IP>:3000` เช่น `http://100.101.102.103:3000`

## สร้างข้อมูลโปเกเด็กซ์ใหม่

ไฟล์ `data/pokedex.json` (Gen 1 ครบ 151 ตัว: ชื่อ ธาตุ ค่าสถานะรวม และ URL ภาพ) commit ไว้แล้ว ปกติไม่ต้องทำอะไร
ถ้าต้องการสร้างใหม่จาก PokéAPI (ต้องต่ออินเทอร์เน็ต):

```bash
node scripts/build-pokedex.js
```

## รันเทสต์

```bash
npm test
```

กติกาเกมอยู่ใน `shared/` ทั้งหมด เซิร์ฟเวอร์เป็นผู้ทอยเต๋าและตัดสินผลเอง หน้าเว็บแสดงผลและส่งคำสั่งเท่านั้น
สเปกเต็มอยู่ที่ `doc/context.md`

## โครงสร้างโปรเจกต์

```
server/   Node.js + Express + Socket.IO
public/   หน้าเว็บ HTML/CSS/JS ธรรมดา (ไม่มีขั้นตอน build)
shared/   กติกาเกม ใช้ร่วมกันทั้งเซิร์ฟเวอร์และเบราว์เซอร์
data/     pokedex.json
doc/      เอกสารและแผนงาน
test/     เทสต์ (node --test)
```
